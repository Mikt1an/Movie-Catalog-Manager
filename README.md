# Movie-Catalog-Manager

main.py — entry point of the application, menu handling, and processing user commands.

mysql_connector.py — MySQL connection and movie search functions.

log_writer.py — stores search queries in MongoDB.

log_stats.py — retrieves statistics from MongoDB (most frequent and recent queries).

formatter.py — output formatting functions (for example, displaying data as tables).

README.md — project description and instructions for running the application (optional).
